# GEOSPATIAL-AND-STATISTICAL-ANALYSIS-OF-IRRAWADDY-DOLPHIN-MORTALITY-IN-BANGLADESH-2000-2024-
Spatial analysis of Irrawaddy dolphin mortality (Orcaella brevirostris) in Bangladesh's Sundarbans (2000-2024). Contains mortality data, statistical analysis code, hotspot identification, risk modeling, and conservation prioritization for 135 dolphin deaths across 29 events.
